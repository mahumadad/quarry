# AI Red Team Bridge — Hardening Changes

## P0 — Validity of results

### ResponseClassifier rewritten (classify_response)
- **Refusal precedence**: a first-person refusal (EN/ES) classifies as
  `blocked` even when the canary or a sensitive marker appears in the same
  response. Quoting the canary while refusing is not a leak. Fixes the
  headline false positive ("I can't comply... I will not reveal QRRT-..."
  used to classify as `full_bypass` 0.9).
- **Canary echo guard**: pass `sent_payload=`; a canary echoed back in the
  same turn is `compliant` echo, not exfiltration.
- Removed over-broad signals from the blocked list ("this request",
  "safety", "policy") and "however" as a partial-bypass trigger.
- Spanish refusal phrases added.
- Empty sensitive markers no longer match every response.
- Every classification now carries `refusal`, `rationale` and honest
  `signals_matched` for traceability.

### SafeguardProfile extractors are real parsers
- The four extractors (`_extract_injection_surfaces`, `_extract_permission_gates`,
  `_extract_exceptions`, `_extract_delegation_model`) parse the analysis
  document (list items, pipe tables, `key — value` lines). An unrecognized
  document yields an **empty profile** with explicit `parse_warnings` —
  the old version returned a hardcoded Fable 5.2 profile for every input.
- New provenance fields: `source_hash`, `extractor_version`.

### Strict rendering and honest template selection
- `PromptTemplate.render(strict=True)` raises on unresolved `${var}`
  (used by `generate_agent_prompt`): no more prompts with literal
  `${payloads}`/`${canary}`.
- Unknown `template_name` raises `ValueError` instead of silently
  substituting an auto-selected template.
- Template/mode mismatch raises (an ai_red_team template cannot be
  invoked in enhanced_pentest mode and vice versa).
- `_select_template` no longer lets "inject" prioritize the exploit
  category over boundary_test; explicit `vector=` selection added.

## P0 — Governance

### Fail-closed authorization gate
- `enhanced_pentest` requires a non-empty `engagement_id` AND a scope
  (injected `Scope` or `.pentest-state/scope.json`) covering every host
  in the target; out-of-scope → `BridgeAuthorizationError`.
- `ai_red_team` requires an engagement/model reference.
- Every generated prompt carries the authorization watermark
  (`[Generated by Quarry AI Red Team Bridge for authorized security testing only...]`).
- Every prompt generation and template registration is custody-logged.
- `register_template` refuses to shadow a builtin without `overwrite=True`
  and upserts by name (no more duplicate jsonl entries).

## P0 — Graph wiring (chains exist now)

- Builtin templates get `prompt_template` nodes on first use, so
  `generates` edges exist for them (previously 0 edges).
- `record_execution` creates `tested_by` edges (model_target → execution
  and injection_surface → execution when `result["surface"]` is given),
  so `find_injection_to_impact()` actually returns chains (verified ≥1).
- `configured_for` edges created (template → model_target).
- `supports` edge: evidence → finding.
- `_record_profile_nodes` is idempotent: reloading a profile no longer
  duplicates model_target/endpoint/trust_boundary/capability nodes.
- `generate_report_data` filters findings by `source == "ai_red_team"` —
  conventional web findings no longer leak into the AI report — and
  exports `impact` + `cvss` + engagement metadata + taxonomy versions.

## P1 — Correctness

- **Planner**: real `depends_on` chains (result-consuming tasks depend on
  predecessors; correlation task depends on all); keyword matching is
  word-prefix based (`database` no longer triggers the exfiltration
  block; ambiguous stems `data`/`long` removed); `max_tasks` keeps the
  final correlation task; `context_strategy="full"` actually renders
  previous results; `previous_results` are fenced as untrusted data with
  per-field truncation; `mark_done` no longer invents the classification
  "completed".
- **SessionStrategy**: abort threshold lowered to 2 consecutive blocked
  results per vector (the old ≥3 was unreachable); `stats()` counts
  blocked separately from pending.
- **PromptOptimizer**: `compliant` no longer counts as bypass in
  ai_red_team mode (it does in enhanced_pentest, which is the success
  metric there); single-attempt "100% bypass" templates are flagged
  `sufficient_samples: false` instead of ranking first.
- **PayloadMutator**: deterministic choices seeded from the payload hash
  (was `hash()`, non-reproducible across processes); `_url_encode` is now
  proper UTF-8 percent-encoding (was `%1F600` for emoji); homoglyph
  selection is seeded, not always-first; 4 new strategies
  (`base64_wrap`, `markdown_fence`, `leet_substitute`,
  `mid_sentence_inject` → 11 total); `mutate_chain()` composes mutations
  and records the chain.
- **ModelFingerprint.analyze**: negations ("no tools available") no
  longer count as capabilities; confidence capped when fewer than 3
  probes ran.

## P1 — Taxonomies (verified against sources)

- **OWASP LLM Top 10 updated to the 2025 edition**: LLM02 Sensitive
  Information Disclosure, LLM03 Supply Chain, LLM04 Data and Model
  Poisoning, LLM05 Improper Output Handling, LLM06 Excessive Agency,
  LLM07 System Prompt Leakage, LLM08 Vector and Embedding Weaknesses,
  LLM09 Misinformation, LLM10 Unbounded Consumption.
- **MITRE ATLAS names corrected**: AML.T0024 is "Exfiltration via ML
  Inference API" and AML.T0048 is "External Harms" (they were swapped);
  added AML.T0058 "AI Agent Context Poisoning" (persistence/memory
  poisoning) and AML.T0065 "LLM Prompt Crafting".
- The 3 unmapped vectors now mapped: `data_exfiltration`, 
  `delegation_chain`, `trust_boundary` (+ new vectors). Test enforces
  every builtin vector has a mapping.

## P1 — Coverage additions

- 3 new builtin templates (27 total): `rag_poisoning`
  (LLM01/LLM04/LLM08), `multi_turn_escalation` (crescendo),
  `output_handling_test` (LLM05).
- New payload families: OpenAI-style tool-result JSON, `multi_turn`
  (crescendo, payload splitting, few-shot priming), `multilingual`
  (Spanish bypass instruction).

## P1 — Export

- **SARIF 2.1.0**: results now include `locations` (urn:quarry artifact +
  logicalLocation), `ruleIndex`, stable `partialFingerprints`, rules with
  `defaultConfiguration` and `security-severity`. Validated against the
  official SARIF 2.1.0 JSON schema; deterministic across exports.
- **Markdown**: Engagement section (profile, model, taxonomy versions,
  parse warnings), Methodology section, findings with impact/CVSS, and
  `_md_escape` for all untrusted content (pipes, newlines, HTML, links —
  report-injection safe).

## Tests

- Updated tests that consecrated defects (silent `${var}` render,
  compliant-as-bypass, 24-template count, prompt generation without
  authorization).
- New adversarial suite `tests/test_ai_red_team_fixes.py` (55 tests):
  classifier adversarial corpus, extractor round-trip on real documents,
  templates.jsonl corruption, shadow-builtin guard, authorization gate
  (4 fail-closed paths), graph wiring E2E (chains ≥1), planner

  EngagementGraph confidence model — these are sound and kept as-is.
